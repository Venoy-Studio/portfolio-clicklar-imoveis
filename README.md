# 💚 Click Lar Imóveis — Sua casa própria a um clique

Plataforma imobiliária digital e vitrine interativa desenvolvida para a **Click Lar Imóveis**, especialista em imóveis residenciais, sobrados de alto padrão e facilitação de financiamento habitacional (Minha Casa Minha Vida e SBPE).

---

## 🌟 Recursos Principais

- **Vitrine Imobiliária Dinâmica**: Exibição detalhada de imóveis com galerias, plantas e especificações técnicas.
- **Simulador de Financiamento**: Ferramenta interativa de cálculo de parcelas e subsídios.
- **Tour em Vídeo & Mídias Otimizadas**: Vídeos e fotos em alta definição com WebP e streaming adaptativo.
- **Conversão via WhatsApp**: CTAs contextuais para cada empreendimento levando ao corretor responsável.
- **Interface Tátil & Fluida**: Desenvolvido com React, TypeScript, Vite e Framer Motion.

---

## 🛠️ Tecnologias

- **React 18** + **TypeScript**
- **Vite** para build ultrarrápido
- **Framer Motion** para animações e microinterações
- **CSS Responsivo Moderno**

---

## 🚀 Como Executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
